# 设置项

入口：**DSH 设置 → 启动动画**。所有改动即时生效，动画在下次播放时使用。

## 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关 |
| 显示模式 | 每次打开都播放 | `每次打开都播放` / `每天一次` |
| 主题 | 暗色 | `暖白`（参考片原色）/ `暗色` |
| 速度 | 1× | 整段动画快慢，0.35–3 |
| 自动播放 | 不自动播放 | `完全自动播放` / `仅需点击一次进入`（需空密码）/ `不自动播放` |
| 允许跳过 | 开 | 右上角 SKIP 与 Esc |

> 手机上没有 Esc，SKIP 是唯一的跳过入口；不需要时可在设置里关掉。

## 身份资料

| 选项 | 作用 |
|---|---|
| 身份名称 | 终幕「欢迎 xxx 访问」里的名字 |
| 身份编号 | 第二步身份卡上的编号 |
| 权限等级 | 第二步身份卡上的权限等级 |
| 访问密码 | 第二步的访问密码；留空则不校验 |

## 语音

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词 |
| 语音来源 | 真声素材 | `真声素材`（随包内联）/ `系统 TTS` |
| 音色 | 智性少女音-CN | 7 种内置真声音色，选音色即决定语种与嗓音 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前两声轻提示 |

内置音色：自动（优先神经网络女声）-US、智性少女音-CN（默认）、
沉稳男声-中文、清冷优雅-日语、低沉沙哑男声-俄语、清冷脆弱-俄语、
威严铿锵宣示-朝鲜语。

> 手机浏览器要求先有一次点击才允许出声，所以第二幕点过按钮之后才有声音。

## 界面音效

| 选项 | 默认 | 作用 |
|---|---|---|
| 界面音效 | 开 | 文字出现、阶段推进的「哒」声 |
| 音效音量 | 0.5 | 不影响台词音量 |
| 音效来源 | 内置素材 | `内置素材` / `现场合成` |

## 视觉

| 选项 | 默认 | 作用 |
|---|---|---|
| 强调色 | `#c70000` | 阶段条、进度条、准星的红 |
| 故障色 A / B | `#ff3b30` / `#ce0912` | 揭幕色散 |
| 人物立绘 | 第 1 款 | 5 款赛博电子风立绘，最后一项「空」= 不显示 |
| 图案 | 东亚防御倡议 | `东亚防御倡议` / `徽章`，同时用于黑幕、左上 logo、终幕 |
| 降世事件窗口 | 关 | 勾选后每次播完都弹；不勾选只在安装后首次播放弹一次 |

## 文案

品牌三行、黑幕三行、终幕方框、页脚均可改。

## 存储

配置保存在 `~/.dsh/dsh-startup.json`（手机上是 DSHA 的 Linux 环境内），
不经过 DSH settings 命名空间，升级插件不会被覆盖。
